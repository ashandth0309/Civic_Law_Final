# Civic Law Initiative

### Law, Liberty & Civic Responsibility
**A Freedom 250 Civic Law Initiative for Sri Lanka**

[Visit the website](https://civiclawinitiative.lk)

## About the Initiative

The **Civic Law Initiative** is an independent, non-partisan civic education initiative focused on improving legal literacy, encouraging responsible civic participation, and strengthening understanding of the rule of law among young people in Sri Lanka.

The initiative brings together civic education, community engagement, and digital resources to make foundational legal and democratic concepts more accessible.

## Our Objectives

- **Build legal literacy:** Help young people understand their rights, responsibilities, and the fundamentals of the law.
- **Promote civic responsibility:** Encourage informed, respectful, and constructive participation in community and public life.
- **Strengthen rule-of-law awareness:** Explore fairness, justice, accountability, and the role of institutions.
- **Encourage dialogue:** Create opportunities for young people from different regions and backgrounds to exchange ideas.
- **Share accessible resources:** Make educational materials and initiative updates available online.

## Getting Started

If you are working with the Next.js application in this repository:

### Prerequisites

- Node.js (use the version required by the project)
- npm or the package manager specified by the repository
- Access to any environment variables required for Firebase or other integrations

### Local Development

```bash
# Clone the repository
# git clone <repository-url>

# Enter the project directory
cd <project-directory>

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit **http://localhost:3000** in your browser.

If the project uses a different package manager or scripts, follow the instructions in `package.json`. Configure local environment variables as required; **do not commit API keys, credentials, or `.env.local` files**.
